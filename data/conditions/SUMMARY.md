## Document extraction: extractor, then verificador

For each investigation, an extractor agent proposed records with verbatim quotes (`extraction/documents/review/<ACC>.extractor.json`); a verificador agent, in a separate run that did not see the extractor's reasoning, tried to break each one (`<ACC>.verificador.json`). Only KEEP and MODIFY records are ingested; `ambiguous` confidence becomes `insufficient_evidence`. `diluent` is the inert gas of the ambient, so statements about the gas inside a burner stream are not ingested as `diluent`. Records whose test_id names no test of the PSI table (planned test-matrix numbers, a paper's own numbering, ground tests outside PSI) are not ingested. This is a segregated internal check by language models, not expert or NASA review.

## Rules applied to every table

- A test condition is the state **before or at the start** of the test. Readings taken after the test ("XO2 after test", "XO2 (final)", "pfinal", "Calibrated final O2") are kept as outcomes (`outcome:o2_mole_fraction_after_test`, `outcome:pressure_after_test`), never as points on a condition axis: a final reading can follow suppression or extinction (BASS-II final O2 goes down to 0.6 %).
- Cells that say there is no single value (en dash, `RAMP`, `RAMPED`, `LOW O2`, `n/a`, spreadsheet errors) give no record and are listed in `extraction/skipped_cells.csv`.
- Unit conversions use exact factors (mmHg x 101.325/760, atm x 101.325, bar x 100, percent x 0.01, micron x 0.001, C + 273.15); a converted value longer than 6 significant digits is rounded to 6, and the record's note says so.
