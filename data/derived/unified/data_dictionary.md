# PYRION PSI combustion data dictionary

One row per extracted condition value. Values and units are copied from data/conditions; no additional conversions are performed. Unit `1` denotes a dimensionless fraction. `o2_mole_fraction` is ambient oxygen; `burner_o2_mole_fraction` is oxygen in the burner stream, not the cabin. Flagged `insufficient_evidence` rows are not observations for calculations. In PSI-69, `outcome:burning_rate` rows with unit mm are flagged insufficient evidence and must not be interpreted as burning rates.

## Columns

- `accession`: PSI investigation identifier.
- `acronym`: Investigation acronym from the manifest.
- `test_id`: Test identifier in the condition extraction.
- `variable`: Condition variable name.
- `value`: Extracted value in the reported harmonised unit.
- `unit`: Unit of value; blank for categorical values.
- `value_original`: Value as recorded by the extraction.
- `unit_original`: Original unit.
- `method`: Extraction method as recorded.
- `source_file`: Path relative to data/raw/; source files are not in the public repo and can be obtained from PSI.
- `source_location`: Location within the source.
- `quote`: Source text recorded by the extraction.
- `status`: Extraction status: extracted denotes a retained extraction; insufficient_evidence is flagged and must not be used as a measurement.
- `note`: Extraction note, including caveats.
- `doi`: Investigation DOI from the manifest.
