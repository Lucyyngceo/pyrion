"+ Add a source" opens a dialog. Only NASA sources are accepted: an NTRS document number from ntrs.nasa.gov, or a NASA CSV or Excel table you upload (up to 20 MB). Typed links are never fetched.

Today the dialog checks your input and shows the five steps that will run (Read, Extract with quotes, Located in the source by code, Classified only if stated, Every scenario recalculated). Processing arrives in the next build, so the submit button is disabled and nothing is added yet.
