**Not on the site today.** The "+ Add a source" button was removed from the Envelope and Data pages; nothing can be added. What follows is the design as it was built.

"+ Add a source" opened a dialog. Only NASA sources are accepted: an NTRS document number from ntrs.nasa.gov, or a NASA CSV or Excel table you upload (up to 20 MB). Typed links are never fetched.

When it was on the site, the dialog checked your input and showed the five steps that would run (Read, Extract with quotes, Located in the source by code, Classified only if stated, Every scenario recalculated). Processing was never built: the submit button was disabled and nothing was ever added.
