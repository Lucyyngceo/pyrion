What it is: A link at the bottom of the Add a source dialog.

What it shows: Nothing by itself; it opens the Data page, which explains how every extracted value is located in the NASA file by code.

How to use it: Click it to read how evidence is checked.

Example: Open it to see the located-by-code counts.

What it does not do: It does not process or add a source; today the dialog only checks your input.
