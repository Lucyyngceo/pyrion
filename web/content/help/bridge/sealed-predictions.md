Before any FM2 result exists, PYRION wrote down what it will and will not say about FM2. The fingerprint (SHA-256) of that text was stamped with OpenTimestamps, which anchors it in the Bitcoin blockchain, so anyone can later check that the text was not changed after results appeared.

The statements are in the predictions README of the repository, linked from the Bridge page.
