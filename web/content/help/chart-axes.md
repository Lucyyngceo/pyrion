What it is: The frame of the chart.

What it shows: Oxygen in % by volume along the bottom and pressure in kPa (psia in brackets when zoomed) up the side.

How to use it: Read values against the ticks.

Example: Find 20.95 % (air).

What it does not do: Units are always shown; a bare number is never used.
