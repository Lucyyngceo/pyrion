What it is: A slider for oxygen.

What it shows: The same oxygen level with NASA tick marks at 21, 26.5 and 34 %.

How to use it: Drag it; hover a tick for its source.

Example: Drag to 30.

What it does not do: It moves in 0.5 % steps; use the number box for finer values.
