All condition values come from the 24 NASA PSI combustion investigations. Each value keeps its file, its location and the quotation it was read from. A validator locates every extracted value in the NASA source by code (a table cell at its row and column, or a quotation word for word).

The Data page shows what was extracted from each investigation, with its DOI and license, and the lineage from PSI files to a verdict.
