What it is: The additional outcomes file linked from the dataset download page.

What it shows: Rows recorded from NASA spreadsheets, including additional ignition and smoke measurements. These are supplied separately from the condition-record download.

How to use it: Choose Download additional outcomes, then read the column definitions and source fields before joining records by investigation and test identifier.

Example: Keep an ignition measurement with its original unit and source when joining it to a test.

What it does not do: A downloaded outcome is not a new engine input or a validated training example merely because it appears in the file.
