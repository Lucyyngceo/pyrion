Condition records are drawn from PSI investigation files and explicitly identified NASA background documents. Each record keeps its source file and location. The Data page distinguishes values located by code from values whose file formats the checker cannot yet read.

The Data page shows what was extracted from each investigation, with its DOI and license, and the lineage from PSI files to a verdict.
