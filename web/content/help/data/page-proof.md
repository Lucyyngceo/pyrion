What it is: A page that gathers the evidence of rigor on one screen.

What it shows: The judge battery result, how many values are located in the NASA source by code, the validator's severities, the independent audits, the test counts, the sealed predictions with their Bitcoin block and the repository's time stamps. Every number is read from a repository file when the site is built.

How to use it: Read it top to bottom; each item has plain words first and links to the files for experts.

Example: Copy the three ots verify lines and check the sealed predictions yourself.

What it does not do: It does not run the checks live and it does not prove that the NASA data is right; it shows that PYRION's checks exist, what they found, and where to repeat them.
