What it is: The links in each section of the Proof page.

What it shows: The repository file behind the statement above the link, on GitHub.

How to use it: Click a link to open the file in a new tab.

Example: Open latest.md to read the validation report.

What it does not do: A link does not re-run anything; it shows the file.
