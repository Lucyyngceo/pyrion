What it is: A small button in an Ask answer.

What it shows: A regime setting the model suggested that your question did not state.

How to use it: Click Apply to add it; it is then marked as added by you.

Example: Apply "fuel phase: solid" if you meant solids.

What it does not do: The model's suggestion is never part of the target until you apply it.
