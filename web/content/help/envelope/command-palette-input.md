What it is: The text box inside the command palette.

What it shows: What you type, filtering presets, sections and pages.

How to use it: Type a few letters, use the arrow keys, press Enter to go.

Example: Type bridge and choose the Bridge page entry. To load a scenario, open Dashboard and select its scenario tile.

What it does not do: It only jumps to things inside PYRION; it does not answer questions.
