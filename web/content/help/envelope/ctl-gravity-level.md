What it is: A number box shown for partial gravity.

What it shows: The gravity level in g, for example 0.165.

How to use it: Type a level.

Example: Type 0.165 for the Moon.

What it does not do: It is shown only; no PSI test is at a partial-gravity level, so it is not compared.
