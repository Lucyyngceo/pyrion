What it is: On phones, the line with the record counts, folded under "Records and sources".

What it shows: How many records were extracted from NASA files, how many are used as evidence, flagged or rejected, from how many PSI investigations, and how many values were located by code in the NASA source.

How to use it: Tap it to open; the link inside goes to the Data page.

Example: Open it to read the same counts the desktop header shows.

What it does not do: It hides nothing permanently; on wider screens the line is always shown.
