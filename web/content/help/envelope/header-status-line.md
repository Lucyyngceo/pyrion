What it is: The one small line under the page title.

What it shows: How many condition values were extracted, from how many investigations, and whether each is located in the NASA source by code.

How to use it: Read it to know how much data stands behind the page; click details for the breakdown.

Example: 10,016 values from 18 of 24 PSI combustion investigations.

What it does not do: It does not say the data is complete: six investigations have no extracted values yet.
