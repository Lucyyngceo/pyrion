What it is: A dialog with a search box and a list of topics by page.

What it shows: Every topic: what it is, shows, how to use it, an example and what it does not do.

How to use it: Type to search; click a topic to read it.

Example: Search "extrapolation".

What it does not do: It documents what exists; unbuilt features are labelled as such.
