What it is: A menu item that switches Help mode on or off.

What it shows: While on, clicking any element opens its topic instead of doing its action.

How to use it: Turn it on, click an element, turn it off.

Example: Click the chart's Full screen while Help mode is on.

What it does not do: While it is on, elements do not perform their action.
