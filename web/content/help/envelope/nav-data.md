What it is: The page about the data behind the envelope: where each value comes from and how many were extracted per investigation.

What it shows: Lineage from PSI files to a verdict, coverage per investigation with DOI and license, and how a value gets into the engine.

How to use it: Click it to audit a number or to see which investigations have extracted values.

Example: Open it to see which of the 24 investigations still have no extracted values.

What it does not do: It does not let you edit data. Adding a source is a separate dialog and its processing is not built yet.
