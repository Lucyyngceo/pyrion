What it is: The row of small status cells above the footer.

What it shows: Facts about the checks behind this build, for example the validation result.

How to use it: Read it to see the state of the evidence pipeline; hover a cell for its meaning.

Example: Look at "Validation: 0 critical findings".

What it does not do: It is not live monitoring of the site, only the last committed report.
