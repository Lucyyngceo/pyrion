What it is: Filters the extracted rows before downloading a CSV.

What it shows: The number of rows matching the selected investigation and variable.

How to use it: Choose either filter and select Download filtered CSV.

Example: Choose an available filter to inspect the records.

What it does not do: This filter does not assess the accuracy or applicability of a row.
