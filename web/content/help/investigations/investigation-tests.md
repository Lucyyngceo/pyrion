What it is: A list of extracted test identifiers and their values.

What it shows: Conditions and recorded outcomes, grouped by test identifier. Each value has its recorded source; a quotation is shown where one was recorded. Flagged records are kept separate.

How to use it: Open Source and status below a value to read its provenance. Use the outcome filter and page controls to narrow the list.

Example: Select the outcome filter to find tests with an outcome field.

What it does not do: It does not establish experimental design or applicability to a new condition.
