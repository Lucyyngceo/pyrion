What it is: A standing sentence about what coverage means.

What it shows: That covered means inside the region spanned by measured test points (interpolated, not necessarily a test at that exact condition), not that flammability behaves the same there.

How to use it: Read it before quoting any coverage figure.

Example: 0 % covered says no PSI test region reaches there; it does not say a flame is safe or unsafe.

What it does not do: It is not a button and it does not change any number.
