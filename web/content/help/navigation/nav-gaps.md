What it is: The Evidence gaps entry of the top bar: it opens the "Evidence gaps that matter" table of the worked example.

What it shows: Every value that is not stated in PSI and blocks a comparison with ISS cabin air, and the range the NASA record would need to state for that investigation to become comparable; for the Moon, the new tests from the Mission Planner.

How to use it: Click Evidence gaps, read the table; each row links to its investigation.

Example: Saffire-III would be inside the tested range if its pressure were stated as 101.0 to 101.8 kPa.

What it does not do: It assumes nothing and adds nothing to the data; it never predicts how a flame behaves.
