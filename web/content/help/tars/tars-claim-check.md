What it is: A panel where you paste a text and each claim in it is classified.

What it shows: A table of claims, each with one class: supported in PSI, not supported in PSI, contradicted or overclaim.

How to use it: Paste the text, press Check the claims, read the table.

Example: A claim naming PSI-69 and a verdict at 30% oxygen is checked against the engine.

What it does not do: It never calls a claim false because PSI is silent: that is shown as not supported in PSI.
