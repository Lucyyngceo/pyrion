What it is: The button that runs the check.

What it shows: A model may help split the text, but every class is decided by code.

How to use it: Press it once the text has at least a sentence.

Example: Paste a paragraph, press it, wait a few seconds.

What it does not do: It does not bypass rate limits; a claim check uses the same allowance as a question.
