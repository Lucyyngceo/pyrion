What it is: The result of a check.

What it shows: Each claim, its class badge, the reason in one fixed sentence, the engine reference with its fingerprint, and NASA quotes that code found on the cited page.

How to use it: Hover a quote to see its page; hover a badge to see what the class means.

Example: A contradicted claim shows the verdict the engine gave.

What it does not do: A discarded proposal is counted, never shown.
