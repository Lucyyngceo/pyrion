What it is: A line above an answer built by code alone.

What it shows: That no model could answer right now, and that everything shown comes from code and NASA documents.

How to use it: Read it; ask again later for a model's explanation.

Example: Ask about a condition while the models are busy and still get the engine's verdicts.

What it does not do: It does not explain or reason; it only retrieves.
