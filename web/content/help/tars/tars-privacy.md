What it is: The small line under the TARS message box.

What it shows: That there is no account, that conversations stay in this browser, and that an anonymous device id (a random number in a cookie) is used only for fair rate limits.

How to use it: Read it; there is nothing to click.

Example: Several people on the same Wi-Fi each have their own allowance because each browser has its own random id.

What it does not do: The id is not linked to a name, an email or an account, and it does not carry your conversations. Clearing cookies gives a new id, but the limit of the whole network still applies.
