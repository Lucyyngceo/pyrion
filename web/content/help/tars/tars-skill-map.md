What it is: A skill button.

What it shows: Builds the three-part answer (Known, Unknown, Next) for the current condition on the Envelope page.

How to use it: Click it after picking a scenario.

Example: Click it on NASA's Moon Base.

What it does not do: It needs a current condition; otherwise it asks you for one.
