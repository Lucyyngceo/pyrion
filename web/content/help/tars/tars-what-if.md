title: What if we ran this experiment?
chapter: tars
order: 5
---
Ask TARS what would change if an experiment were run, for example a PMMA rod at 34 % oxygen and 8.2 psia in lunar gravity. TARS adds one hypothetical test to the records in memory and shows how the verdict counts and the map would change.

Every such answer carries a banner: **Hypothetical: not a measurement.** The simulated test is never saved to the data, and it exists only in that answer.
