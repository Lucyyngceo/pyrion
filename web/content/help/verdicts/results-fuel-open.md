What it is: A note shown when your condition does not state a fuel phase.

What it shows: That liquid droplet and gas-flame investigations are then compared alongside solid materials, because an axis you leave open is not compared.

How to use it: For cabin materials such as fabrics and plastics, set the fuel phase to solid in the condition panel; the list then keeps the solid-fuel investigations.

Example: ISS cabin air leaves the fuel phase open, so FLEX droplets can rank first.

What it does not do: It does not change any verdict by itself; the engine still compares only the axes you set.
