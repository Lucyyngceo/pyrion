What it is: The verdict-count summary, shown as labelled counts in the current dashboard.

What it shows: The number of investigations with extracted records, split by verdict.

How to use it: Hover a row for the split by extrapolation level.

Example: Read how many are applicable.

What it does not do: Investigations with no extracted values are excluded from the verdict counts and are listed separately.
