What it is: The box above the table of contents.

What it shows: Matching topics from titles, keywords and the start of each topic.

How to use it: Type two letters or more and click a result.

Example: Type zoom.

What it does not do: It is a keyword search, not an AI search; for a conversation use TARS SI.
