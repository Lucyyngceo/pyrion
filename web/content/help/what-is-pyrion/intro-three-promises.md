**The verdict is deterministic.** The same condition and the same data always give the same verdict and the same fingerprint. A language model never decides a verdict.

**Every evidence value has a recorded source.** Its receipt identifies the NASA file and location. The Data page reports which values the validator located by code and which could not be checked. Computed numbers and PYRION conventions are labelled separately.

**PYRION says what it does not know.** Where PSI has no test, or where the records do not state what is needed, the answer is "insufficient evidence" or "no PSI test in this regime". It says "in PSI", never "no data exists".
